ecma376standard_password.docx is an unmodified independent Office 2007 Standard
Encryption fixture from msoffcrypto-tool. Password: Password1234_
Source: https://github.com/nolze/msoffcrypto-tool/blob/master/tests/inputs/ecma376standard_password.docx
License: LICENSE-msoffcrypto.txt (MIT).

standard-vectors.json is generated by generate-standard-vectors.py using Python
hashlib SHA-1 and cryptography AES-ECB. The generator checks its key derivation
against msoffcrypto's published Password1234_ example before writing vectors.
It does not call RecoverKit. Regenerate with Python 3 and cryptography installed.
