agile-vectors.json is generated by generate-agile-vectors.py using independent
Python hashlib SHA-1/SHA-512 and cryptography AES-CBC, without RecoverKit code.
The generator first verifies the published hashcat 8.0.0 module_09500.c and
module_09600.c self-test hashes. Regenerate with Python 3 and cryptography.

Accepted vectors match hashcat 8.0.0 exactly: 2010/SHA-1/AES-128 or
2013/SHA-512/AES-256, 100000 spins and 16-byte salt. Unsupported AES key sizes
and spin counts are valid independent encryption vectors used to check parser
rejection and variable-count native/managed spin chains. Raw F4 vectors provide
literal UTF-16 surrogate units to avoid Python's stricter UTF-8 decoder.
Both hashcat kernels compare only the first 16 verifier-hash bytes; tests also
check that changing the second encrypted verifier-hash block has no effect.

agile-msoffcrypto-sha1.bin and agile-msoffcrypto-sha512.bin are independent Office
Agile OLE encrypted-package fixtures generated by msoffcrypto-tool 6.1.0
(MIT, LICENSE-msoffcrypto.txt). The SHA1 fixture configures its password key
encryptor for SHA1/AES-128 and retains SHA512 for package integrity; the SHA512
fixture uses the unmodified SHA512/AES-256 defaults. Both use msoffcrypto
parameter generation, payload encryption, integrity generation and OLE container
methods directly so the SHA1 protector can coexist with SHA512 package integrity.
Password: independent-\u00e9-\U0001f510 (Python escapes, e acute and lock emoji).
The generator decrypts both complete ZIP payloads with HMAC integrity
verification. It also verifies the SHA512 password directly. msoffcrypto 6.1.0
has a SHA1 password-verifier padding bug; the password-derived payload key and
HMAC independently confirm the SHA1 password without that helper. Regenerate with
--msoffcrypto and msoffcrypto-tool installed. Deterministic randomness is exclusively for reproducible test data.
Source: https://github.com/nolze/msoffcrypto-tool/blob/master/msoffcrypto/method/ecma376_agile.py
